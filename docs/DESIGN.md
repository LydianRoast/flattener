# Design references

The interface uses a consistent progression from files to output settings to conversion results. Dense document information sits on matte surfaces; narrow frames and restrained reflective accents organize the controls. Status is expressed in text as well as color. The dark and light palettes retain the same hierarchy, layout and keyboard behavior.

The source references inform these decisions; they are not a prescriptive software standard.

Libre Baskerville supplies the serif typography throughout the application. Its traditional forms provide a consistent serif style, with larger small-label sizes to retain readability. The same family is used for controls, headings, body text and the license viewer.

| Reference | Relevant principle | Application |
| --- | --- | --- |
| Manfred Maier, *Basic Principles of Design*, volume 1, pp. 10–14 | Develop the whole structure before details; use coherent proportions and deliberate linear accents | Aligned panels and compact, consistent controls |
| Volume 2, pp. 76–82 | Readability depends on character relationships, spacing and line rhythm | One readable typeface, regular row spacing, restrained emphasis |
| Volume 3, pp. 10–11 and 74–75 | Evaluate material, color and form together; limit competing variables | Matte working areas and narrow chrome accents |
| Volume 4, pp. 11–18 and 30–33 | Judge color by relative value, brightness and quantity | Graphite and blue structure, limited red emphasis and frosty highlights |
| Volume 4, pp. 42–49 | Function and recognizable structure precede ornament | One primary action and persistent per-file results |

[CARI Vectorheart](https://cari.institute/aesthetics/vectorheart) informs the square, precise framing and typographic restraint. [CARI Y2K Aesthetic](https://cari.institute/aesthetics/y2k-aesthetic) informs the limited reflective treatment. [CARI Frutiger Aero](https://cari.institute/aesthetics/frutiger-aero) contributes restrained gloss rather than a full desktop imitation.

The reference books and CARI gallery images are not redistributed. The application draws its own interface and does not copy gallery artwork.
