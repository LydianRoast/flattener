# OCR document fixture

`ocr-document.jpg` is page 1 of the original synthetic document generated by `examples/validation_fixture.rs`, rendered at 150 DPI. It contains an inverted heading, ordinary body text, colored and grayscale blocks, and a saved form appearance. It contains no user document data.

The fixture is used to test full-page recognition and word positions. Small isolated-word tests do not catch a detector threshold mismatch that produces false positives across the page. The test requires the heading, body text, and form value to be found without accepting page-sized word bounds.

The fixture is distributed under the repository MIT license. PDF standard-font substitute rendering uses the separately attributed PDFium/Foxit font data described in `docs/THIRD_PARTY.md`.
