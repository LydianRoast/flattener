# Libre Baskerville

Flattener uses Libre Baskerville for its interface text, including controls and the license viewer.

Source: [Google Fonts / Libre Baskerville](https://github.com/google/fonts/tree/b3d4b3ba7c4d54f15ed2be72d7f58b9097c3b252/ofl/librebaskerville).

The unmodified variable regular font is stored as `LibreBaskerville.ttf` for a stable asset path. Upstream filename: `LibreBaskerville[wght].ttf`.
