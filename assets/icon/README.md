# Flattener icon

The application icon depicts a black ink bottle with a red feather quill and restrained silver highlights. The original artwork is AI-generated and was created for Flattener and is supplied under the repository's MIT terms to the extent applicable.

`flattener-source.png` is the transparent master artwork. `flattener.png` is the 256-pixel application-window image. `flattener.ico` contains 16, 20, 24, 32, 40, 48, 64, 128, and 256-pixel Windows launcher images. The Rust packaging example derives these files with premultiplied-alpha resampling.
